# 🧑‍🏫 Adaptive SQL Tutor

An intelligent tutoring system for SQL that adapts to each student's knowledge using Bayesian Knowledge Tracing (BKT) and provides two kinds of hints: **rule‑based** (fast, deterministic) and **generative AI** (smart, contextual, powered by a local LLM).

## ✨ Features

- 📚 **Adaptive problem selection** – after each answer, the system picks the next problem targeting your weakest SQL skill.
- 🧠 **Bayesian Knowledge Tracing** – a probabilistic model of your mastery of `WHERE`, `JOIN`, `GROUP BY`, `NULL` handling, and more.
- 💡 **Rule‑based hints** – instant hints for common mistakes (`= NULL`, missing `GROUP BY`, missing quotes, etc.).
- 🤖 **AI hints (Ollama)** – free, local, offline‑capable LLM (Meta’s Llama 3.2) that generates contextual hints without sending your data to the cloud.
- 📊 **Skill mastery dashboard** – see your progress for each SQL concept in the sidebar.
- 🧪 **Pre‑/post‑test ready** – easily extendable for user studies.

## 🚀 Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/kmanche4675/sql-tutor-ai.git
cd sql-tutor-ai

2. Create and activate a virtual environment
Windows (PowerShell):

bash
python -m venv venv
.\venv\Scripts\Activate.ps1
macOS / Linux:

bash
python3 -m venv venv
source venv/bin/activate

3. Install Python dependencies
bash
pip install -r requirements.txt
requirements.txt includes: streamlit, pandas, sqlglot, ollama.

4. Set up the SQLite database
bash
python database/init_db.py
This creates database/tutor.db with sample employees and departments tables.

5. Install and run Ollama (for AI hints)
Ollama runs a local LLM on your machine – completely free, no API key required.

Download Ollama from ollama.com and install it.

Pull the model (one time, ~2GB):

bash
ollama pull llama3.2
Verify Ollama is running – it usually starts automatically after installation. You can test with:

bash
ollama list
You should see llama3.2 in the list.

💡 If you ever see a connection error in the app, run ollama serve in a separate terminal – but normally the background service is enough.

6. Run the SQL Tutor
bash
streamlit run app.py
Your browser will open at http://localhost:8501.

🎮 How to Use
Select a problem from the sidebar.

Write an SQL query in the text area.

Click Submit – the system executes your query against the real database and compares results.

Need help?

💡 Rule Hint – instant, deterministic hint based on common mistake patterns.

🤖 AI Hint (Ollama) – waits 2–5 seconds, then gives a smart, contextual hint generated by the local LLM.

After a correct answer, click 🎯 Adaptive Next Problem – the tutor chooses the next problem that targets your weakest skill.

Watch your skill mastery bars in the sidebar grow as you learn.

🔧 Extending the Tutor
Add more SQL problems
Edit problems.py and follow the existing structure. Each problem needs:

id, title, description

expected_sql

compare_columns (list of columns to compare, or None for all)

skills – list of skill tags (e.g., ["basic_where"]). These must match the skills in student_model.py.

Add a new skill for BKT
Add the skill name to SKILLS in student_model.py.

Add default parameters (p_mastered, p_learn, p_guess, p_slip) to PARAMS.

Tag problems with the new skill in problems.py.

Use a different local LLM
In evaluator.py, change the model parameter in the ollama.chat() call from llama3.2 to any model you have pulled (e.g., phi4, mistral, llama3.3).
